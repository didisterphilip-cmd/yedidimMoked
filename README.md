# אפליקציית מוקד ארצי

אפליקציה פשוטה לאנדרואיד לרישום קריאה ויצירת שלוש הודעות מוכנות להעתקה (WhatsApp).

## מה האפליקציה עושה

1. **התחברות ראשונה** — מזינים **מספר מוקדן** ו**שם מלא**. הם נשמרים במכשיר ולא צריך להזין אותם שוב (אפשר לערוך בכל רגע דרך גלגל השיניים ⚙ למעלה).
2. ממלאים את שדות הקריאה:
   - שם של מי שהתקשר
   - מספר טלפון של מי שהתקשר
   - **עיר** — מקלידים שם עיר והמערכת מזהה אוטומטית את ה**מרחב** (למשל: רחובות → השפלה). אם העיר לא מזוהה, נפתח שדה להזנת מרחב ידנית.
   - **שכונה** — מופיע רק כשהעיר היא ירושלים; נכנס בהודעה לפני הכתובת עם פסיק.
   - כתובת
   - סוג ודגם הרכב + שנה
   - סוג הסיוע
   - פרטים / הערות
   - קישור של מיקום בגוגל מפות
3. שלוש ההודעות נבנות אוטומטית, ולכל אחת יש **כפתור העתקה נפרד**.

### סוגי מקרה (כפתור ☰ בפינה הימנית העליונה)

לחיצה על ☰ פותחת בחירה של סוג המקרה למילוי:
- **מקרה בסיסי** — הטופס המקורי (עיר/מרחב, כתובת, רכב, סוג סיוע וכו') עם שלוש ההודעות.
- **משיכת רכב תקוע** — טופס קצר: מיקום נוכחי (קישור לגוגל מפות), תזכורת לצלם 4 תמונות של הרכב מכל הכיוונים ממרחק ~10 מ׳, סוג הרכב + דגם, שם המתקשר ומספר הטלפון. נוצרות שתי הודעות להעתקה: (1) שם ומספר המתקשר, ובשורה שמתחת מספר המוקדן; (2) קישור המיקום בגוגל מפות.

הבחירה נשמרת ונטענת בפתיחה הבאה.

### לשוניות (טאבים)

בתחתית המסך יש שתי לשוניות:
- **קריאה חדשה** — טופס הקריאה והודעות ההעתקה (כמתואר למעלה).
- **שיחות ממספר** — כמה שיחות קיבלת ממספר מסוים:
  - **יומן השיחות של הטלפון** — קורא את יומן השיחות האמיתי של המכשיר ומראה כמה שיחות נכנסות קיבלת מהמספר. זמין **רק באפליקציה המותקנת (APK)**, ודורש אישור הרשאת "גישה ליומן שיחות" בפעם הראשונה. בגרסת הדפדפן (PWA) האפשרות הזו אינה זמינה.
  - **מונה ידני** — עובד בכל גרסה. כל שיחה שאתה מעתיק (הודעה 2) נספרת אוטומטית לפי מספר המתקשר, ואפשר גם להוסיף/לבדוק/למחוק מספרים ידנית. הנתונים נשמרים במכשיר בלבד.

### מבנה ההודעות

**הודעה 1:**
```
*מוקד ארצי מרחב (מרחב שזוהה מהעיר)*
(שכונה, אם ירושלים)(כתובת)
(סוג ודגם הרכב + שנה)
*(סוג הסיוע)*
(פרטים / הערות)
```
> ה**מרחב** מחושב אוטומטית מהעיר. עבור ירושלים, ה**שכונה** מופיעה לפני הכתובת עם פסיק (למשל: `רמות, רחוב הרצל 5`).

### עריכת רשימת הערים והמרחבים

מיפוי הערים למרחבים נמצא בקובץ **`www/cities.js`** — מסודר לפי מרחב.
זו טיוטה שכדאי לעבור עליה ולתקן לפי החלוקה הרשמית: מוסיפים עיר לרשימת המרחב המתאים, או מעבירים עיר בין מרחבים. אחרי שינוי ודחיפה לענף — האתר מתעדכן אוטומטית.

**הודעה 2:**
```
(שם של מי שהתקשר), (מספר טלפון של מי שהתקשר)
(מספר המוקדן שלך)
```

**הודעה 3:**
```
(קישור של מיקום בגוגל מפות)
```

> הכוכביות `*...*` הן ההדגשה (bold) של WhatsApp — הן מועתקות כמו שהן ומודגשות אוטומטית כשמדביקים.
> שדה ריק פשוט מושמט מההודעה.

## איך משיגים את קובץ ה‑APK ומתקינים בטלפון

הבנייה מתבצעת אוטומטית ב‑GitHub Actions (לא צריך מחשב עם Android Studio).

1. אחרי שהקוד נדחף לענף, נכנסים ב‑GitHub ללשונית **Actions** → **בניית אפליקציית אנדרואיד (APK)** ומחכים שהבנייה תסתיים (סימן ✓ ירוק).
2. הכי נוח: נכנסים ל‑**Releases** של המאגר, פותחים את הגרסה **אפליקציית מוקד ארצי (גרסה אחרונה)**, ומורידים את הקובץ **`moked-artzi.apk`** — אפשר לעשות זאת ישירות מדפדפן הטלפון.
3. פותחים את הקובץ בטלפון ומאשרים התקנה. בפעם הראשונה אנדרואיד יבקש לאפשר "התקנה ממקורות לא ידועים" עבור הדפדפן/מנהל הקבצים — מאשרים.
4. האייקון של האפליקציה יהיה הלוגו.

> אפשר גם להריץ בנייה ידנית: Actions → הבחירה בתהליך → **Run workflow**.

## החלפת האייקון בתמונה שלך

האייקון נוצר מהקובץ `www/icon.svg`. אם רוצים להשתמש בקובץ תמונה מקורי במקום:
- מחליפים את `resources/icon.png` בתמונה מרובעת שלכם (מומלץ 1024×1024),
- מוחקים בקובץ `package.json` את הקריאה ל‑`gen:icons` בתהליך הבנייה **או** מעדכנים את הסקריפט,
- דוחפים לענף — הבנייה תיצור אייקונים חדשים אוטומטית.

## פיתוח מקומי (לא חובה)

```bash
npm install
npm run gen:icons                 # יוצר PNG מהלוגו
npx cap sync android
cd android && ./gradlew assembleDebug
# ה‑APK: android/app/build/outputs/apk/debug/app-debug.apk
```

בזמן פיתוח אפשר לפתוח את `www/index.html` בדפדפן כדי לבדוק את הלוגיקה.
